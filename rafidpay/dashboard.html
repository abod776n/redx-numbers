ملف التاجر

أدخل بيانات صاحب الحساب ووسيلة التواصل وعنوان النشاط. قد نطلب التحقق من الهوية عبر مزود تحقق آمن عند الحاجة.

مفتاح API

أنشئ مفتاحاً لاستخدامه من الخادم الخلفي. لن يظهر المفتاح كاملاً مرة أخرى بعد إغلاق الرسالة.

لا ترسل المفتاح إلى العميل ولا تحفظه في JavaScript أو تطبيق الهاتف. خزّنه كمتغير بيئة سري في الخادم.
