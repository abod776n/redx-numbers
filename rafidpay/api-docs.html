RafidPay — وثائق API

الإصدار v1 · REST/JSON · Sandbox فقط

تنبيه مهم

هذه النسخة تنشئ ملفات تجار وروابط دفع وسجل عمليات تجريبية فقط. لا يوجد تحصيل أموال حقيقية أو تسوية مالية أو تكامل مع بنك/محفظة. حالة sandbox_paid لا تعني وصول المال.

المصادقة

استخدم مفتاح التاجر في ترويسة Authorization. لا تضع المفتاح في كود المتصفح.

Authorization: Bearer rp_live_YOUR_API_KEY
Content-Type: application/json

يتم إنشاء المفتاح عبر POST /api/rafidpay/v1/keys بعد تفعيل حساب التاجر. يظهر المفتاح مرة واحدة فقط.

إنشاء حساب تاجر

POST /api/rafidpay/merchant
Cookie: talabati_session=...
{"business_name":"متجري","country_code":"YE"}

يتطلب تسجيل الدخول إلى طلباتي. الدول المتاحة في النموذج: YE, SA, AE, IQ. حالة الحساب الجديدة pending وتحتاج موافقة الإدارة.

إنشاء مفتاح API

POST /api/rafidpay/v1/keys
Authorization: Bearer rp_live_EXISTING_KEY
{"name":"مفتاح المتجر"}

إنشاء رابط دفع

POST /api/rafidpay/v1/payment-links
Authorization: Bearer rp_live_YOUR_API_KEY
{"title":"فاتورة 102","description":"وصف اختياري","amount":12.5,"currency":"USD"}

العملة USD أو YER. تعاد بيانات الرابط العام في الاستجابة.

قائمة روابط الدفع

GET /api/rafidpay/v1/payment-links
Authorization: Bearer rp_live_YOUR_API_KEY

تفاصيل رابط عام

GET /api/rafidpay/public/links/{slug}

لا يحتاج إلى مصادقة.

محاكاة الدفع

POST /api/rafidpay/public/links/{slug}/sandbox-pay
Content-Type: application/json
{"customer_name":"Customer","customer_email":"customer@example.com"}

يعمل فقط عند ضبط RAFIDPAY_SANDBOX_ENABLED=true. ينشئ عملية sandbox_paid ولا يسحب أموالاً.

سجل العمليات

GET /api/rafidpay/v1/transactions
Authorization: Bearer rp_live_YOUR_API_KEY

يعرض آخر 100 عملية للتاجر.

الأخطاء

  • 400 INVALID_PAYMENT_LINK — بيانات غير صحيحة.
  • 401 INVALID_API_KEY — المفتاح غير صالح.
  • 403 MERCHANT_NOT_ACTIVE — التاجر غير مفعل.
  • 404 ENDPOINT_NOT_FOUND — المسار غير موجود.
  • 500 INTERNAL_ERROR — خطأ داخلي.

مثال Node.js

const r = await fetch("https://YOUR_DOMAIN/api/rafidpay/v1/payment-links", {
  method: "POST",
  headers: {
    "Authorization": "Bearer " + process.env.RAFIDPAY_API_KEY,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    title: "Invoice 102",
    amount: 12.5,
    currency: "USD"
  })
});
const data = await r.json();
console.log(data);
