🔐 مفاتيح API الخاصة بك

أنشئ مفتاحًا لكل مشروع. سيظهر المفتاح كاملاً مرة واحدة فقط.

جارٍ تحميل المفاتيح...

⚡ نقاط النهاية المتاحة

GET /api/v1/balance
GET /api/v1/services
GET /api/v1/countries?service=tg
POST /api/v1/order
GET /api/v1/order/{order_id}
GET /api/v1/orders

جميع الأسعار بالدولار. يُحجز المبلغ عند إصدار الرقم ويُعتمد الخصم عند وصول الكود.

📘 التوثيق السريع

أرسل المفتاح في ترويسة Authorization أو X-API-Key. جميع الاستجابات بصيغة JSON.

مثال: جلب الدول
curl "https://talabati-numbers-website-production.up.railway.app/api/v1/countries?service=tg" \
  -H "Authorization: Bearer YOUR_API_KEY"
مثال: طلب رقم جديد
curl -X POST "https://talabati-numbers-website-production.up.railway.app/api/v1/order" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: order-unique-001" \
  -d '{"service":"tg","country_code":"0"}'
مثال JavaScript (على الخادم فقط)
const response = await fetch(BASE_URL + "/api/v1/balance", {
  headers: { Authorization: "Bearer " + process.env.TALABATI_API_KEY }
});
const balance = await response.json();

رموز الحالات: waiting = بانتظار الكود، done = وصل الكود، refunded = مسترد، uncertain = قيد المراجعة. أرسل Idempotency-Key فريدًا لكل عملية شراء لمنع تكرارها.

🛡️ الأمان والاستخدام

  • لا تضع المفتاح في JavaScript الخاص بالمتصفح.
  • استخدم HTTPS فقط.
  • أنشئ مفتاحًا منفصلًا لكل بوت أو موقع.
  • يمكنك إلغاء أي مفتاح فورًا.
  • لا تعاود شراء الطلب إذا كانت حالته قيد المراجعة.

🧾 آلية الفوترة

  • الطلب يستخدم رصيد حسابك في طلباتي نمبر.
  • تُحجز قيمة الرقم أثناء انتظاره.
  • يُعتمد الخصم النهائي عند وصول الكود.
  • عند فشل المزود المؤكد لا يتم تحصيل قيمة الطلب.
